Welcome to HeroTrack

The ultimate Heroclix tournament tracking app

🎯 Built for Tournament Players

HeroTrack is designed for competitive Heroclix players who want to track their performance, analyze trends, and improve their game. With mobile-first design and offline capabilities, you can log matches quickly between rounds and review your stats anytime.

Fast Match Entry

Quick match logging optimized for mobile use between tournament rounds.

Performance Analytics

Track win rates, points trends, and performance metrics over time.

Mobile First

Responsive design with large touch targets for easy mobile use.

Offline Ready

Local storage with IndexedDB for offline tournament tracking.

Team Photos

Upload screenshots of your teams to remember successful builds.

Customizable

Configure which fields to show and set your preferred defaults.

Ready to Get Started?

Install Node.js and npm, then run the following commands to start the development server:

npm install
npm run dev

The app will be available at http://localhost:3000
