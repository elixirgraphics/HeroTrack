🔧 Troubleshooting

If Google Script fails to load: Check your internet connection and try refreshing

If Client ID is invalid: Make sure you copied the full Client ID from Google Cloud Console

If OAuth initialization fails: Check that your domain is added to authorized origins

If sign-in doesn't work: Open browser dev tools and check the console for errors
