📋 Troubleshooting Checklist

If you see "Network error: Failed to fetch":

  1. Check Google Cloud Console → APIs & Services → Credentials
  2. Edit your OAuth 2.0 Client ID
  3. In "Authorized JavaScript origins", add EXACTLY:
    http://localhost:3001
    (No https, no trailing slash, exact port)
  4. Save and wait 5-10 minutes for changes to propagate
  5. Check OAuth Consent Screen is configured
  6. Enable required APIs: Google Identity Services API
